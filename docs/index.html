Add a job board

Paste any job board, search results page, RSS feed or company careers page. Company boards (Greenhouse, Lever, Ashby, Workable, Personio…) are tracked directly; other sites are read as pages and also looked up through search.

Connection

Refreshing and adding boards need a GitHub token, kept only in this browser. Make a fine-grained token for this repository only, with Actions: read and write and Contents: read and write.

Boards to check yourself

The radar can't read these boards, so check them yourself. Each link opens the board with the search filled in where the board allows it. Opening one marks it as checked for today.
